# 行星防卫战（Planetary Defense War）

像素画风的塔防：虫群顺着通道（或者从四面八方）涌向水晶核心。开局地图是空的，玩家用晶矿造兵营、机器人车间、
坦克、火炮，买巨舰、叫轰炸支援，设集结点把兵力派到前线；核心被打碎就输。

```bash
npm install
npm run dev        # http://localhost:5192
npm run build      # 类型检查 + 打包到 dist/
npm run figures    # 离线出图：.preview-*.png（不用开浏览器）
```

地图：00 新兵训练场（窄通道 + 新手提示）、01 轨道平台 α、02 赤沙峡谷（沙漠）、03 静海月面、
04 冰封前哨（落雪，无巡航舰）、05 虫巢核心（最难）、06 远征号甲板（全速航行的巨舰背上）、
07 十字高地（建造模式，核心在中央高台上，四条路四面来虫）。
加一张图 = `game/fields.ts` 加一个战场 + `menu/data.ts` 加一条展示数据。

启动后先进主界面（地图列表 / 地图详情 / 商城、成就入口），点"开始游戏"才开一局，左上角"主界面"返回。
整个游戏放在一块 16:9 的舞台里，大小夹在 960×540 和 1920×1080 之间（`app.ts` 的 `VIEW_MIN` / `VIEW_MAX`）；
主界面按 1280×720 排版后整体缩放。

镜头：滚轮缩放，左键拖动平移。

## 技术路线

- **Pixi.js v8** 只用来把三角形送上 GPU；所有东西都是程序化的基础图形，没有贴图。
- **像素管线**（`render/pixelSurface.ts`）：先画进一张低分辨率缓冲，再整数倍最近邻放大。五层：
  地面（不描边）→ 单位（整层描一圈一像素暗边）→ 特效（光、烟、血条，不描边）→ 天空（巨舰、炮艇、炸弹，描边）→ 天上的光（不描边）。
  天空那两层压在地面所有东西上面，巨舰飞过能盖住下面的单位、血条、子弹和炮火。
- **伪 45° 投影**（`render/projection.ts`）：地面纵向压到 0.7，高度保留 0.74。
- **ShapeBatch**（`render/shapeBatch.ts`）：画家顺序的图形批次（矩形、椭圆、杆、圆、四边形），按深度基数排序。
- **人物**（`characters/`）：19 单位高的骨架 + 两骨 IK；`renderer.ts` 把每个部件画成"平涂 + 一条硬边阴影"，
  动力装甲兵在同一具骨架上加大肩甲、背包、装甲腿和腰甲。`poses.ts` 是走路和倒地。
- **模型**（`mesh/`）：`Mesh3` 是带矩阵栈的即时模式 3D 建模（盒子、六面体、楔形、棱柱），面按法线分四档明暗、
  背面剔除、画家排序，再投影成平涂多边形。`models.ts` 里是这个游戏用到的全部载具和建筑，全部原创造型，
  统一走蓝白黑涂装（`LIVERY_BLUE`）。
- **离线预览**（`tools/preview.ts`）：跑的是游戏里那份绘制代码，只把最后一步光栅化换成自己写的扫描线，
  所以出的图和游戏里一模一样（包括描边）。

## 战场

**平台**（`floor.ts`）：前方通道窄（宽 350）、后方炮位区宽（470），两侧是带视差星空和星云的虚空。
地板是 20 单位一格的金属面板，按种子挑平板 / 对开板 / 防滑纹 / 格栅 / 警示舱盖 / 排风扇 / 灯条；
边缘是带警示条和指示灯的护边，底下挂着托架。金属地板炸不出坑，爆炸只留焦痕；飞出平台的碎块掉进虚空。

**虫群**（`bugs.ts`）：和人一样是局部 3D 点投影成平涂色块，六条腿三角步态交替抬。六种：

| 虫 | 特点 |
|---|---|
| 小爬虫 | 数量最多、跑得快 |
| 跳虫 | 后腿长，一蹦一蹦地扑过来 |
| 甲虫 | 个头大、背上一排骨刺、耐打 |
| 刺蛇 | 贴地蜿蜒的蛇尾 + 直立上身 + 眼镜蛇式骨刺冠 + 一对骨镰；走到阵前停下，举镰一砸，朝防线从地里刺出一串地刺 |
| 喷酸虫 | 发光酸囊，停下来往防线吐抛物线酸液 |
| 飞虫 | 高射炮和机甲导弹的目标 |

死法：瘫倒（翻过来、腿蜷着），或者被打爆成一把甲壳碎片。血迹每一滩现生成，各种虫的体液颜色不同。

**守军**（都是玩家造出来的，见下面的「建造模式」）

- **机枪兵**：动力装甲，三发一个点射，射程是以自己为圆心的圆，打最近的虫；开火前先转身对准，弹道和朝向一致。
- **步行机甲**（`walkerMech`）：反关节双腿、两臂双联机炮、肩上导弹巢、背后动力舱。在集结点附近踱步，
  每 2~4 秒齐射四枚追踪导弹（优先打飞虫）。
- **攻城坦克**（`siegeTank`）：四个履带舱 + 粗壮的液压驻锄。咬住一个虫堆几秒，炮塔慢慢转过去，对准才开炮。
- **火炮**（`aaTurret`）：双管交替开火，优先打飞虫，没有飞虫就打地面。
- **巨舰 / 战列巡航舰**（`battlecruiser`）：买下后停在战场旁边缓缓漂浮。一轮攻击是"慢慢转向对准 → 蓄能（锁死方向和落点）
  → 光弹飞行 → 中心一炸再连环炸开一圈"，整轮期间不转向；主炮冷却 14~18 秒。
- **轰炸支援**（`gunship`）：花钱叫一组炮艇，飞过虫最密的地方投弹。
- **兵营 / 机器人车间**（`barracks` / `mechFactory`）：出兵时升门、门里亮灯，单位从正门走出来。

## 正式玩法

所有地图都是建造模式：开局清空（没有预置的守军、炮塔、兵营、指挥中心，也没有铺满通道的虫），只有水晶核心和一笔初始晶矿；
虫一波一波地来：开局 20 秒准备，之后每 30 秒一波，第 n 波 6 + 5(n-1) 只（乘每张图的 `waveScale`），陆续刷出。
右上角是波次面板（当前波、剩余虫数、下一波多少只和倒计时）；倒计时没走完时点「下一波」，按剩余秒数给晶矿（每秒 3），
下一波立刻来、和场上的叠加。每来一波上方闪"第 N 波来袭"。波次数值在 `scene.ts` 开头的 `WAVE_*`、`EARLY_BONUS`。炮艇不再自动掠过，只有花钱叫的轰炸支援；
巨舰（战列巡航舰）要在建造列表里买（一局一艘，1500），买下后从画面外飞到待命位置自动开主炮（冰封前哨买不了）。
巨舰只打射程圈里的虫（基础 460）；点它（或点建造列表里"巨舰 · 已部署"）弹出升级面板（攻击力、射程、射速，不能卖），
选中时画射程圈，右键地面让它先转身对准、再非常慢地开过去（每秒约 8），移动中不攻击。
巨舰主炮落地、轰炸支援的炸弹各轻微震一下屏幕，别的爆炸不震。新兵训练场有引导，其余地图开局直接开打。

## 建造模式（00 新兵训练场）

- 开局地图是空的，只有水晶核心，给 200 晶矿，不刷怪。引导一步步带着做：造兵营 → 选中兵营、右键设一次集结点（亮出兵营连同它整个集结点范围）。
  引导时整个画面压暗，只亮出这一步要操作的地方（建造列表的某一项 / 建造区 / 某座建筑），压暗的地方点不到；
  引导面板贴在亮出来的地方旁边。要玩家动手的那一步会等玩家做到再自动往下走；走完或点「跳过引导」才开始刷怪。
- 右上角晶矿下面是建造列表（数字键 1~6）：兵营、机器人车间、坦克、火炮、巨舰、轰炸支援。点一项进入放置模式，
  鼠标下出现建筑虚影：能放是绿、不能放是红（要在防线后面、整块落在平台上、不压核心和别的建筑）。左键放下，右键 / Esc 取消。
- 兵营、车间自动生产，头顶一排方块是生产进度（和血条一个样式）、下面是「现有 / 上限」。造好后升门，单位从正门走出来，
  绕开所有建筑走到集结点：士兵在集结点排成方阵（路上射程里有虫就停下开火，打完接着走），机甲在集结点附近左右小范围踱步
  （多台左右错开）。选中兵营 / 车间时显示集结旗，右键地面改集结点，名下的单位全部改走过去。
  机枪兵阵亡后尸体清掉，兵营看到人数不够会接着造。
- 单位有碰撞体积（士兵半径 6、机甲 14）：互相推开、推出建筑占地。走路的单位不推站定的单位，只自己让开；
  走到集结点附近（30 以内）被挡住，或者卡住走不动，就在原地停下当作到了。方阵位置会避开建筑和核心。
- 寻路：撞上楼（或核心）就从它外围的角点绕过去，挑每段都不穿楼、总长最短的走法；终点贴着楼时那座楼只按单位半径算。
  机甲小角度边走边转，大角度才原地转身（不算卡住）；卡住先从当前位置重新寻路，两次不行才跳过路径点或就地停下。
  机甲撞上士兵是士兵让路，被挤开的士兵等它过去自己走回原位。新盖的楼占住了谁的目标位置，谁就换个附近的空位。
  兵营方阵从集结点往前排（不压到后面机甲的巡逻线）；机甲的踱步范围避开建筑和核心。
- 集结点离建筑最远 220（`RALLY_MAX`），选中兵营 / 车间时地上画出这个范围；点得更远就放在范围边上。
- 升级面板半透明，除了按钮都让鼠标穿过去（隔着面板也能右键设集结点）；底部「出售」点两次确认，
  退还总花费（造价 + 已花的升级）的 70%，它造出来的兵和机甲一起撤走（避免卖了再造无限刷兵）。
- 选中坦克 / 火炮（以及放置它们时）地上画射程圈；鼠标停在升级面板的「射程」那一行，再画一圈虚线表示升级后的射程。
- 建筑、炮塔、机甲都有血量和血条（士兵从兵营出来时就带着血条）。漏过防线的虫先扑向附近（150 以内）的建筑 / 机甲，
  咬一口自己炸掉，附近没有才直奔核心；机甲在巡逻线上也会挨咬，地刺、酸液落在附近同样会伤到。打空就炸毁：
  炮塔连炮一起没了，机甲炸掉后车间会补造。血量在 `buildings.ts`（建筑）和 `scene.ts` 的 `MECH_HP`（机甲），都是占位。
- 有能升级的线、而且晶矿付得起的建筑，头顶会出现一个旋转的绿色向上箭头。
- 升级：点地图上的建筑，头顶弹出面板，每条升级线一行，各自独立升级（各 3 级）：兵营 / 车间是数量、生产速度、攻击力、射程、射速；
  坦克 / 火炮是攻击力、射程、射速。轰炸支援每次 500 晶矿，叫一组炮艇沿虫最多的那一列投弹。
- 所有数值在 `game/buildings.ts`（造价、各升级线每级的数值和价钱、生产时间），都是占位。
- 兵营 / 车间的升级线：数量、生产速度、攻击力、射程、射速；坦克 / 火炮：攻击力、射程、射速。

## 十字高地（07）

水晶核心在地图正中一座方形高台上（高 26），上下左右四条路通到地图边，接上高台的那一段是坡道；路和高台以外是走不了的崖壁。
建造模式，开局 500 晶矿直接开打，建筑只能放在高台上，出兵建筑的默认集结点是离自己最近的坡道顶。
虫从四条路的尽头刷出来沿路冲上坡道（单位、虫、建筑、核心都按地形垫高），寻路会绕开四个角上的崖壁，
方阵朝"从核心指向集结点"的方向排，轰炸支援炸虫最密的一团。刺蛇、喷酸虫的攻击是按"防线在正前方"写的，这张图先不出。

## 射程

所有守军（机枪兵、机甲、坦克、高射炮 / 火炮）的射程都是以自己为圆心的圆，打离自己最近的目标（坦克仍挑虫堆）。

## 核心与晶矿

- **水晶核心**（`floor.ts` 的 `CORE`）：单通道地图在防线后方的中轴上，十字高地在正中的高台上。漏过防线的虫
  扑向附近的建筑 / 机甲，没有就直奔核心；撞上核心就扣血、自己炸掉。核心血打空 = 失败，弹结算（重新开始 / 返回主界面）。
- **晶矿**：每打死一只虫加一点，右上角显示；核心血条画在核心正下方（两排方块 + 读数）。`KILL_REWARD`（击杀奖励）、`CORE_DMG`（撞核心扣血）、`CORE_HP` 都是占位数值。
- **晶矿只在本局有效**，不带出这一局；主界面只显示信用点。

## 信用点与存档

- **信用点**跨局保存（`src/save.ts`，存在浏览器 localStorage 的 `pdw-save-v1` 里），主界面右上角显示。局内的获得方式（`scene.ts` 里的 `CREDIT_DROP`、`CREDIT_MILESTONE`、`MILESTONE_BASE`）：
  - 打死虫子按概率随机掉落几点，越难打的虫越容易掉、掉得越多；掉落时虫的位置飘起一个金色的「+N」。
  - 每突破 5 波发一笔：第 k 次发 25×k，再随机多给 0~50%；和「第 N 波来袭」一起显示「突破第 N 波 · 信用点 +M」。
  - 挣到就存（中途退出、刷新页面都不丢）；右上角晶矿下面显示本局挣到多少，失败结算里也有一行。
- **地图解锁**：一开始只有 00 新兵训练场能玩；走完训练场的引导（或者点「跳过引导」）就开放其他地图，不用通关。
  地图数据里 `afterTutorial: true` 的图受这条限制。

## 地图范围

- **地图范围**：地图顶边 `TOP_Y = 0`，虫从顶边外刷进来。镜头横向最远到地图最宽处
  （至少装得下默认取景），纵向在地图顶边和底边之间。

## 伤害

机枪兵 30 血（头顶 5 格血条），机甲 60 血（8 格），建筑血量见 `buildings.ts`。受到的伤害：

| 来源 | 伤害 |
|---|---|
| 冲到防线的虫扑上来咬一口（随后被近距离打死） | 小爬虫 1、跳虫 2、甲虫 3 |
| 刺蛇的地刺 | 4 |
| 喷酸虫的酸液 | 2 |
| 漏过去的虫扑到建筑 / 机甲 / 核心身上（自己炸掉） | 按 `CORE_DMG` |

机枪兵血打空就往后倒下，尸体躺 7 秒后清掉，兵营看到人数不够会接着造。数值都在 `game/scene.ts` 开头。
