# 行星防卫战（Planetary Defense War）

一条悬在深空里的金属平台，虫群顺着通道从上方涌下来；动力装甲机枪兵守在防线上，身后有步行机甲巡逻，
再往后是攻城坦克、高射炮、兵营和指挥中心，侧面的虚空里停着一艘战列巡航舰。

目前是**视觉场景 + 第一点游戏性**（机枪兵会阵亡、兵营补人），还没有玩家操作。

```bash
npm install
npm run dev        # http://localhost:5192
npm run build      # 类型检查 + 打包到 dist/
npm run figures    # 离线出图：.preview-*.png（不用开浏览器）
```

地图：00 新兵训练场（窄通道 + 新手提示）、01 轨道平台 α、02 赤沙峡谷（沙漠）、03 静海月面、
04 冰封前哨（落雪，无巡航舰）、05 虫巢核心（最难）。
加一张图 = `game/fields.ts` 加一个战场 + `menu/data.ts` 加一条展示数据。

启动后先进主界面（地图列表 / 地图详情 / 商城、成就入口），点"开始游戏"才开一局，左上角"主界面"返回。
整个游戏放在一块 16:9 的舞台里，大小夹在 960×540 和 1920×1080 之间（`app.ts` 的 `VIEW_MIN` / `VIEW_MAX`）；
主界面按 1280×720 排版后整体缩放。

镜头：滚轮缩放，左键拖动平移。

## 技术路线

- **Pixi.js v8** 只用来把三角形送上 GPU；所有东西都是程序化的基础图形，没有贴图。
- **像素管线**（`render/pixelSurface.ts`）：先画进一张低分辨率缓冲，再整数倍最近邻放大。三层：
  地面（不描边）→ 单位（整层描一圈一像素暗边）→ 特效（光、烟，不描边）。
- **伪 45° 投影**（`render/projection.ts`）：地面纵向压到 0.7，高度保留 0.74。
- **ShapeBatch**（`render/shapeBatch.ts`）：画家顺序的图形批次（矩形、椭圆、杆、圆、四边形），按深度基数排序。
- **人物**（`characters/`）：19 单位高的骨架 + 两骨 IK；`renderer.ts` 把每个部件画成"平涂 + 一条硬边阴影"，
  动力装甲兵在同一具骨架上加大肩甲、背包、装甲腿和腰甲。`poses.ts` 是走路和倒地。
- **模型**（`mesh/`）：`Mesh3` 是带矩阵栈的即时模式 3D 建模（盒子、六面体、楔形、棱柱），面按法线分四档明暗、
  背面剔除、画家排序，再投影成平涂多边形。`models.ts` 里是这个游戏用到的全部载具和建筑，全部原创造型，
  统一走蓝白黑涂装（`LIVERY_BLUE`）。
- **离线预览**（`tools/preview.ts`）：跑的是游戏里那份绘制代码，只把最后一步光栅化换成自己写的扫描线，
  所以出的图和游戏里一模一样（包括描边）。

## 目录

```
src/
  main.ts, app.ts       入口、Pixi 初始化
  core/math.ts          向量与数学小工具
  render/               相机、投影、像素管线、图形批次、颜色；snapshot.ts 离屏出小图（主界面预览、敌人图标）
  characters/           骨架、IK、配色、动力装甲兵的画法、走路 / 倒地姿势
  mesh/                 Mesh3 建模与绘制；载具和建筑模型
  fx/effects.ts         爆炸、炮口焰、烟、碎块
  menu/                 主界面（DOM 层）：地图列表、地图详情、商城 / 成就入口；data.ts 是展示数据
  game/
    main.ts             镜头（取景、缩放、拖动）和主循环
    scene.ts            战场：单位、虫群、射击、伤害、补兵、绘制
    bugs.ts             虫子的画法、血迹
    fields.ts           战场定义：每张地图的通道宽窄、主题、虫群构成、有没有巡航舰 / 炮艇
    floor.ts            太空平台：金属地板、护边、托架、星空
    surface.ts          行星地表（沙漠 / 冰原 / 月面 / 虫巢）：同一套画法、四套 SurfaceStyle
    ground.ts           平台地面（平的；平台外是虚空）
tools/preview.ts        离线出图
```

## 战场

**平台**（`floor.ts`）：前方通道窄（宽 350）、后方炮位区宽（470），两侧是带视差星空和星云的虚空。
地板是 20 单位一格的金属面板，按种子挑平板 / 对开板 / 防滑纹 / 格栅 / 警示舱盖 / 排风扇 / 灯条；
边缘是带警示条和指示灯的护边，底下挂着托架。金属地板炸不出坑，爆炸只留焦痕；飞出平台的碎块掉进虚空。

**虫群**（`bugs.ts`）：和人一样是局部 3D 点投影成平涂色块，六条腿三角步态交替抬。六种：

| 虫 | 特点 |
|---|---|
| 小爬虫 | 数量最多、跑得快 |
| 跳虫 | 后腿长，一蹦一蹦地扑过来 |
| 甲虫 | 个头大、背上一排骨刺、耐打 |
| 刺蛇 | 贴地蜿蜒的蛇尾 + 直立上身 + 眼镜蛇式骨刺冠 + 一对骨镰；走到阵前停下，举镰一砸，朝防线从地里刺出一串地刺 |
| 喷酸虫 | 发光酸囊，停下来往防线吐抛物线酸液 |
| 飞虫 | 高射炮和机甲导弹的目标 |

死法：瘫倒（翻过来、腿蜷着），或者被打爆成一把甲壳碎片。血迹每一滩现生成，各种虫的体液颜色不同。

**守军**

- **机枪兵**：动力装甲，三发一个点射，只打自己正面 ±60、210 以内的虫；开火前先转身对准，弹道和朝向一致。
- **步行机甲**（`walkerMech`）：反关节双腿、两臂双联机炮、肩上导弹巢、背后动力舱。两台在防线后来回巡逻，
  射程 300、扇面 ±150，每 2~4 秒齐射四枚追踪导弹（优先打飞虫）。
- **攻城坦克**（`siegeTank`）：四个履带舱 + 粗壮的液压驻锄。咬住一个虫堆几秒，炮塔慢慢转过去，对准才开炮。
- **高射炮**（`aaTurret`）：双管交替开火，打飞虫。
- **炮艇**（`gunship`）：每隔十来秒一组从下往上掠过投弹。
- **战列巡航舰**（`battlecruiser`）：停在平台右侧的虚空里缓缓漂浮。一轮攻击是"慢慢转向对准 → 蓄能（锁死方向和落点）
  → 光弹飞行 → 中心一炸再连环炸开一圈"，整轮期间不转向；主炮冷却 14~18 秒。
- **兵营 / 指挥中心**（`barracks` / `commandCenter`）：平台最后方。兵营出兵时升门、门里亮灯，屋顶烟囱冒烟；
  指挥中心楼顶雷达在转、天线闪红灯。

## 核心与晶矿

- **水晶核心**（`scene.ts` 的 `CORE`）：兵营和指挥中心中间，地图中轴上，一颗浮着的水晶。从防线缺口漏过去的虫
  直奔核心，路过巡逻机甲脚边会被顺手打掉；撞上核心就扣血、自己炸掉。核心血打空 = 失败，弹结算（重新开始 / 返回主界面）。
- **晶矿**：每打死一只虫加一点，右上角显示；核心血条画在核心正下方（两排方块 + 读数）。`KILL_REWARD`（击杀奖励）、`CORE_DMG`（撞核心扣血）、`CORE_HP` 都是占位数值。
- **地图范围**：地图顶边 `TOP_Y = 0`，虫从顶边外刷进来，开局就铺满整条通道。镜头横向最远到地图最宽处
  （至少装得下默认取景），纵向在地图顶边和底边之间。

## 游戏性（第一版）

机枪兵 30 血，头顶 5 格血条（一格 6 血；剩 4~5 格绿、2~3 格黄、最后一格红）。受到的伤害：

| 来源 | 伤害 |
|---|---|
| 冲到防线的虫扑上来咬一口（随后被近距离打死） | 小爬虫 1、跳虫 2、甲虫 3 |
| 刺蛇的地刺 | 4 |
| 喷酸虫的酸液 | 2 |

血打空就往后倒下，尸体躺 7 秒。空缺排进兵营的队列：兵营 3 秒造一个，造好了升门，新兵端着枪走出来、
绕过兵营走回那个站位。没人守的缺口虫会穿过去，冲到机甲巡逻线才被打倒。

无画面模拟（前 3 分钟）：约每 8 秒倒下一个，在岗最少 7/13，会补回来。数值都在 `game/scene.ts` 开头：
`MARINE_HP`、`BITE`、`SPIKE_DMG`、`ACID_DMG`、`BUILD_TIME`。
